# Noot Study 2.0

Noot Study 2.0 rebuilds daily study around a searchable library, usable multiple-choice quizzes, and revision that starts with material you already saved.

## A redesigned Mac workspace

- Paper-and-ink light and dark themes, grouped sidebar navigation, clearer study actions, and redesigned settings.
- Explicit model, reasoning, response-detail, and provider controls.
- One daily allowance across the dashboard, subjects, review queue, reminders, and ARIA shortcuts.

## Flashcards you can practise

- Select an option, press **Check answer**, receive corrective feedback, and finish a multiple-choice set with a score.
- Answer options shuffle between attempts; restarting clears previous answers and scores.
- Open a single saved question or start a quiz from a filtered set.
- Select several topics and card formats in Card Studio, edit drafts, and retain successful results when another topic fails.

## Find and reuse material

- **Library** searches cards and saved tests by subject, unit, topic, and content.
- **Reuse saved cards first** fills revision sets before requesting new material. A fully covered set needs no generation request.
- ARIA and generation receive saved questions and answers with IDs so an equivalent learning point can reopen the original card.
- Duplicate filtering preserves records and history. Repeated copies remain inspectable.

## Review limits that hold across the app

- Scheduled reviews stop at the configured allowance, with a ceiling of 40 distinct cards. Lower goals and intensity limits are respected.
- Already-reviewed cards cannot return through another queue or a duplicate copy.
- The allowance resets at local midnight, including daylight-saving transitions.
- Free practice remains available without changing FSRS scheduling or recorded totals.

## Saved tests and feedback

- Save practice exams and exam-marker questions with curriculum scope.
- Reopen answers, continue writing, and request criterion-based feedback.
- Marking checks available marks and labels results without a supplied scheme as practice estimates.
- Saved tests are protected from old-chat cleanup; practice estimates do not become school grades.

## Local build and compatibility

- **Version:** 2.0.0, build 4.
- **Platform:** macOS 14 or later.
- **Distribution:** source tag and release notes, with no attached binaries or installers.
- The bundle identifier and existing library are preserved. Quit the previous app before replacing it, and keep a backup.
- No personal stores, reports, credentials, or private course materials are included. Screenshots use demo content with blurred identity areas.

Compilation and validation run locally on macOS. The version tag does not start a hosted runner. See the [README](https://github.com/leofratu/nootstudy/blob/v2.0.0/README.md) for screenshots, feature walkthroughs, and local build commands.

## Validation

- The Release configuration compiled locally with Xcode 26.0.1 on Apple Silicon, with version 2.0.0 and build 4 verified in the built app.
- The local macOS test run passed: 354 tests reported across 58 suites. The opt-in documentation preview was run separately.
- Quiz selection, topic filters, and demo screenshots were checked with external computer-use tools. Noot Study does not capture the screen or request screen-recording permission.
- Provider-dependent regressions use fixtures; no live GPT-5.6 Sol requests were used for validation.
